More Details

Grids in this game ALWAYS have as few red tiles as possible. Complete districts in number order: first create every red-majority district, then pack all remaining blue tiles into blue districts.

A valid solution MUST:
- have one more than half of the districts be red and one less than half be blue
- have blue-majority districts contain only blue tiles
- have red-majority districts contain the fewest red tiles possible while still holding a majority
